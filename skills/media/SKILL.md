keywords: [youtube, video, videos, audio, mp3, mp4, song, music, podcast, download, clip]
---
- To find a video: `search_youtube`, then give the user the best match or download it.
- `download_audio` saves the audio track; `download_video` saves the video. Both need a full URL.
- Downloads can take a while; tell the user where the file was saved.
